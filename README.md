# Multi-Agent CSV ML Assistant

Multi-Agent CSV ML Assistant is a Streamlit-based data review tool for rapid assessment of tabular datasets. The application uses LangGraph to orchestrate specialist workflow nodes, deterministic Python tools for factual analysis, and optional LangChain/OpenAI synthesis for stakeholder-ready report writing.

## Operational Context

The system supports early-stage machine learning discovery work where teams need a fast, repeatable review of a new dataset before committing to deeper modelling. Dataset facts are calculated with pandas and scikit-learn utilities rather than generated by an LLM, which keeps the core analysis reproducible and testable.

## LangGraph Workflow

```text
profile_dataset -> assess_data_quality -> recommend_models -> synthesize_report
```

- **profile_dataset:** calculates dataset shape, data types, missing values, and duplicate rows.
- **assess_data_quality:** converts profile findings into cleaning recommendations.
- **recommend_models:** infers target type and recommends baseline model families.
- **synthesize_report:** produces a Markdown report through deterministic fallback or optional LangChain/OpenAI synthesis.

## Execution Modes

- **Deterministic fallback:** runs without API keys and generates the report from structured tool outputs.
- **LLM-assisted synthesis:** uses `langchain-openai` when `OPENAI_API_KEY` is configured. The LLM receives structured summaries only, not the full raw CSV by default.

## Capabilities

- CSV upload with bundled sample data fallback
- Dataset preview and target-column selection
- LangGraph node execution trace in the UI
- Structured profile, quality, and model recommendation outputs
- Downloadable dataset review report for handoff or documentation

## Local Run

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Optional LLM-assisted synthesis:

```powershell
Copy-Item .env.example .env
# set OPENAI_API_KEY in .env
streamlit run app.py
```

## Notes

LangSmith tracing is optional and disabled by default. The deterministic path is the default reliability baseline for local review and interview demos.
